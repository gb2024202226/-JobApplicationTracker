ℹ️ About Job Application Tracker

A simple web application to manage and track job applications.

🎯 Project Purpose

The Job Application Tracker helps students and job seekers organize their job applications in one place.

Users can record companies, job roles, application dates, and application statuses.

🚀 Features

📋 Add and manage job applications

🔍 Search applications by company

✏️ Edit application information

🔄 Update application status

🗑️ Delete applications

📅 Sort applications by date

📊 View application statistics

📈 Calculate selection rate

🎓 Check company eligibility using CGPA

➕ Add custom companies and CGPA requirements

🛠️ Technologies Used

🐍 Python

🌐 Flask

🎨 HTML

🎨 CSS

💾 JSON

📚 Project Type

This is a beginner-friendly software project designed to demonstrate Python programming, web development, file handling, and basic data management.
